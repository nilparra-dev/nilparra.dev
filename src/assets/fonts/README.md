# MS Sans Serif font files

These two WOFF2 files are generated by `scripts/font/build_ms_sans_serif.py`
from the React95 port kept in `scripts/font/react95/`:

- Source: `react95/dist/fonts/ms_sans_serif.woff2` and
  `ms_sans_serif_bold.woff2` from `react95@4.0.0`
- Package: https://www.npmjs.com/package/react95
- Repository: https://github.com/react95-io/React95
- Package and repository licence: MIT, copyright Artur Bień
- Font metadata: `Copyright lou 2017`, CC BY-SA 3.0
  (https://creativecommons.org/licenses/by-sa/3.0/); preserve those terms when redistributing
  the font files.

The generated files preserve the source font metadata. See
[`NOTICE.md`](NOTICE.md) for provenance, attribution and the licence link.

The port draws every glyph like the 8 pt bitmap of Windows 95, but it had 27
advance widths off by a pixel (the space was 2 px instead of 3), no accented
letters (the browser borrowed them from another typeface) and no `<`, `>`,
`` ` `` or `|`. The script keeps the React95 glyph shapes, places them with
the Windows 95 advance widths, draws the missing Latin-1 letters and symbols,
sets the 13 px line of the original and derives the bold face the way Windows
95 did (every pixel repeated one column to the right).

To rebuild with Python 3.9 or newer:

```bash
python -m pip install -r scripts/font/requirements.txt
python scripts/font/build_ms_sans_serif.py
python scripts/font/build_ms_sans_serif.py --check
```

The second command rebuilds the files; `--check` verifies that two fresh builds
are identical and match the committed WOFF2 files. The output is committed, and
`npm run build` does not run the font generator.

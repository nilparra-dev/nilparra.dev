# Windows 95 wallpaper bitmaps

These are archived Microsoft Windows wallpaper BMP files, downloaded without
conversion or resizing on 2026-09-17. They are not generated artwork and are not
covered by this project's MIT license. Copyright remains with the original owners.

Binary source:
https://cs.gettysburg.edu/~duncjo01/archive/patterns/windows/Windows%2095&98/

Windows 95 inclusion, filenames and dimensions were cross-checked against:
https://windowswallpaper.miraheze.org/wiki/Windows_95?oldid=19484

The archive combines Windows 95 and 98 material and dates the English copies
1999-04-23. These 18 images are documented as included in Windows 95 and reused
in Windows 98/Me. This is not a claim that the bytes were extracted from a
verified Windows 95 installation disc.

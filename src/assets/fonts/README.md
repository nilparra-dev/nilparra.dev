# MS Sans Serif font files

These two WOFF2 files are copied from the `react95@4.0.0` npm package:

- Source: `react95/dist/fonts/ms_sans_serif.woff2`
- Source: `react95/dist/fonts/ms_sans_serif_bold.woff2`
- Package: https://www.npmjs.com/package/react95
- Repository: https://github.com/react95-io/React95
- License: MIT, copyright Artur Bień (the package includes the MIT license)

They are used only as the local UI font. The application does not use React95
components or its theme at runtime.
